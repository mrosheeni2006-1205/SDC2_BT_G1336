# NeuroInsight AI - Multimodal Brain Tumor IDH Classification

**NeuroInsight AI** is a professional medical decision-support application for binary **Isocitrate Dehydrogenase (IDH)** mutation status classification in brain tumors. It fuses volumetric 3D MRI data across four modalities (`T1`, `T1ce`, `T2`, `FLAIR`) with clinical demographic features (`Age`, `Sex`) using a **Multimodal 3D CNN + Vision Transformer** architecture.

---

## ⚠️ Important Medical Disclaimer

> **This application is a research and educational decision-support system. Its predictions are generated by a machine-learning model and should not be interpreted as a definitive medical diagnosis. Clinical decisions must be made by qualified healthcare professionals using appropriate clinical evidence.**

---

## Key Features

- **Multimodal 3D MRI Processing**: Independent voxel intensity standardization over non-zero voxels for T1, T1ce, T2, and FLAIR NIfTI (`.nii` / `.nii.gz`) volumes.
- **Deep Multimodal Fusion**: 3D CNN feature map tokenization into 384 tokens, processed by a 2-layer 4-head Vision Transformer and fused with clinical embeddings.
- **Strict Preprocessing Alignment**: Reproduces exact training transformations using PyTorch trilinear interpolation (`[1, 4, 128, 128, 96]`, `align_corners=False`).
- **Research Dashboard**: Polished medical UI featuring multi-step workflow, real-time stage progress, probability distribution bar charts, and downloadable clinical text reports.
- **Privacy & Security**: Zero permanent storage of raw patient MRI files; secure temporary volume handling with automatic cleanup.
- **Graceful Model Validation**: Dynamic health reporting indicating whether the model `.pth` checkpoint and training `age_scaler` parameters are configured.

### Backend
- **Framework**: Python 3.11+, FastAPI, Uvicorn
- **ML / Medical Imaging**: PyTorch, NiBabel, NumPy, SciPy
- **Validation & Schemas**: Pydantic v2, Pydantic-Settings
- **Testing**: PyTest with synthetic NIfTI generation

### Frontend
- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons, Glassmorphism design system

## Installation & Setup

### Prerequisites
- Python 3.10+
- Node.js 18+ and npm
- (Optional) Docker & Docker Compose

### 1. Backend Setup
```bash
# Navigate to backend
cd backend

# Install Python dependencies
pip install -r requirements.txt

# Run backend PyTest verification
python -m pytest tests/ -v

# Start FastAPI development server
uvicorn app.main:app --reload --port 8000
```
Backend server will start at `http://localhost:8000`. Swagger API docs available at `http://localhost:8000/api/v1/docs`.

### 2. Frontend Setup
```bash
# Navigate to frontend
cd frontend

# Install node dependencies
npm install

# Build production bundle
npm run build

# Start Vite development server
npm run dev
```
Frontend application will start at `http://localhost:5173`.

## Model Checkpoint & Scaler Configuration

To attach your trained model weights and training scaler:

1. Place your trained PyTorch checkpoint in:
   ```
   backend/model/best_multimodal_cnn_vit_idh.pth
   ```

2. Enter your training `StandardScaler` mean and scale values in `backend/model/preprocessing_config.json`:
   ```json
   {
     "age_scaler": {
       "mean": 55.4,
       "scale": 14.2
     },
     "sex_mapping": {
       "M": 0.0,
       "F": 1.0
     },
     "mri_modalities": [
       "T1",
       "T1ce",
       "T2",
       "FLAIR"
     ],
     "target_shape": [
       128,
       128,
       96
     ],
     "class_mapping": {
       "0": "IDH Wild Type",
       "1": "IDH Mutated"
     }
   }
   ```

When the checkpoint is placed and scaler values are set, `GET /api/v1/health` will report `"status": "ok"` and `"model_loaded": true`.

## API Summary

- `GET /api/v1/health`: Returns health status and model readiness.
- `POST /api/v1/analyze`: Accepts `patient_id`, `age`, `sex`, and four NIfTI files (`t1`, `t1ce`, `t2`, `flair`), returning classification and probabilities.
- `GET /api/v1/analysis/{id}`: Fetches analysis record.
- `GET /api/v1/analysis/{id}/report`: Downloads formatted plain text report.
